# 친애

퇴근길에 걱정을 음성으로 맡기고, 출근길에 하나씩 돌려받아 정리하는 Pleos Connect 차량 전용 음성 앱

## APK

[`apk/SongSeungHwan_Chinae_release.apk`](apk/SongSeungHwan_Chinae_release.apk)

## 실행 방법

**에뮬레이터:** APK 설치 → 앱에서 설정 후 **시작하기** → Virtual Console로 좌석(운전석만)과 기어를, 내비로 집·회사 경로를 바꿔 진행.

**휴대폰(심사용):** APK 설치 → 마이크 권한 허용 → **시작하기** → 왼쪽 아래 시험용 버튼으로 진행.

- **실제 사용 순서 :** 맡기기 &gt; 돌려받기 &gt;&gt; 앱 초기화(처음부터 다시 할때 사용함)
- **차량 신호:** 집·회사로 경로, 집 도착, 기어 P·D, 동승자 탑승, +5분(목적지까지 걸리는 시간)

## 테스트 환경

- Pleos Connect Emulator 2.1.0 (Android 14 automotive), 화면 2560×1440, density 160
- 휴대폰: Android 9 이상. 모바일 앱에는 차량용 음성(Pleos)이 없어 ElevenLabs(합성)와 기본 음성 인식을 씀
